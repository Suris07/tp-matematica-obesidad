# Información del TP en GitHub

El trabajo práctico se encuentra subido a un repositorio de GitHub:

https://github.com/Suris07/tp-matematica-obesidad

En el repositorio se incluyen los siguientes archivos:

- **tp_mate_obesidad.ipynb:** notebook con el desarrollo del trabajo práctico. Contiene el análisis realizado, el código, los gráficos y las conclusiones.
- **ObesityDataSet.csv:** dataset utilizado para desarrollar el análisis sobre los niveles de obesidad, los hábitos alimentarios y la condición física.

El trabajo fue realizado en **Google Colab**. El notebook puede abrirse y ejecutarse en esa plataforma; para reproducir el análisis, se debe mantener el archivo CSV disponible y utilizar la ruta correcta al cargar el dataset.
